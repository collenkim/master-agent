# 구축 이력

이 문서는 초기 구축 순서를 요약한 이력이다. 현재 기능과 후속 작업의 기준은 [구현 현황](implementation.md), 실행 절차는 [README](../README.md), 성공·실패 근거는 [검증 기록](verification.md)을 따른다.

| 단계 | 구축한 범위 |
| --- | --- |
| 실행 기반 | Node.js ESM·SQLite, 프로젝트·그룹·목표, 계획 검증·판단 선저장·프로젝트 잠금, 모의 실행 |
| 근거와 계획 | 지정 문서·코드 수집, 출처·줄·해시, Codex·Claude CLI 분석, 계획 재검토·질문·활성화 |
| 개발과 검증 | Claude 호스트 배정·관측·같은 세션 재개, 독립 명령·변경 파일·산출물 검증, 인계·통합 완료 |
| 복구와 재계획 | 실패 분석·범위 내 수정·재검증, 종료 확인 후 변경 보존·근거 재수집·새 계획, 반환 기록 기반 관측 복구 |
| code-agent 통신 | 원자적 접수·위임 판단·이벤트·정지·재부착·제어권 인계, 반영 커밋·영수증 대조 |
| LangGraph 전환 | 실행·계획·복구·재계획·모의 실행·Mission 변경 명령을 그래프로 통일, SQLite 체크포인트 저장 |
| 실제 모델 검증 | 앞선 답 판단 5건과 두 격리 프로젝트의 세 작업 전체 흐름 완료 |

초기의 무의존성 실행 기반은 LangGraph 도입 이후 잠금 파일 기반 설치로 바뀌었다. 현재는 `npm.cmd ci --ignore-scripts`로 설치한다. 모의 실행 완료·실제 모델 완료·제품 전체 목표 달성은 서로 구분한다.

독립 프로젝트의 병렬 개발·구조화 계약 인계·진행 상태 구분은 master 통신 경로에 구현했다. UI·원격 운영·동시 실행 수 제한·다양한 실제 업무 품질 평가는 후속 범위다. 미확인 실행을 자동 성공이나 중복 실행으로 바꾸지 않는 원칙은 유지한다.
