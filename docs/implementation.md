## 이번 연결의 경계

master는 함수·입력 범위·반환·오류 선언을 계약 문서의 정확한 원문과 연결한다. 소스 검사와 문서 해시·반영 커밋이 일치해야 후속 작업으로 인계한다. 후속 호스트는 첫 담당 배정 전에 code-agent의 `planning contracts` 명령으로 등록하며, code-agent가 재검증한 사본을 담당 입력과 입력 해시에 포함한다. 형식과 한도는 [검증 계약](live-verification.md)에 있다.

실제 실행에서 발견한 진행 표시 누락도 보완했다. code-agent의 단계 이벤트 `to` 값을 읽고, 위임 승인이 적용된 뒤 호스트가 재개되기 전의 단계 변경도 같은 시도의 진척으로 반영한다. 작업 ID를 대조해 완료된 작업에 후속 작업의 이벤트가 섞이지 않도록 했다.

두 격리 프로젝트의 실제 병렬·인계·통합은 56분 30초에 완료됐다. 세 작업 모두 succeeded이며 후속 담당 배정 7건의 계약 입력 해시를 대조했다. 질문·사람 이관은 0건이다. 상세 근거는 [검증 기록](verification.md)을 따른다.

code-agent의 계약 등록·답 출처·결과 응답·계획 검사 보완은 별도 세션에서 `8085647`로 완료됐다. 이 작업에서는 해당 저장소를 수정하지 않았다. 실제 모델 시험에 사용하는 별도 사본의 빌드·템플릿 1,027개 파일이 현재 빌드와 동일함을 SHA-256으로 확인했다. 캡처 당시 원본 HEAD는 `2552d3a`였고 위 보완이 미커밋 상태였으므로 캡처 HEAD와 후속 완료 커밋을 구분한다.

## 남은 작업

1. 실제 모델의 실패 수정·재계획·프로세스 중단·재부착을 격리 저장소에서 연속 검증한다. 정상 흐름 성공과 자동 회귀만으로 이를 대신하지 않는다.
2. 자유 목표의 AI 계획 생성부터 검증 계약 연결·개발·통합 완료까지 한 번에 실행한다. 현재 전체 흐름 시나리오는 고정 master 계획으로 시작한다.
3. 더 큰 업무 사례와 Codex 개발 호스트로 확장한다. 웹 중지·승인·답변, 원격 러너·운영 예산·카탈로그 자동 갱신은 별도 범위다. 현재 웹은 관제·그룹 편집·그룹/단일 요청·이어 실행을 제공한다.
4. 설치 이후의 init·doctor·update 명령과 배포 패키징을 보완한다. 현재는 로컬 소스를 npm 전역 명령으로 연결하며 공개 npm·단일 실행 파일 배포는 제공하지 않는다.
