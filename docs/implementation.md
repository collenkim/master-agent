## 실행 경계

계획 생성은 수집한 소스 ID·본문 인용·프로젝트 배정·문서 버전을 검증한다. 프로젝트 등록 참조만으로 문서 근거를 대신하지 않는다. 오류를 재검토 피드백으로 전달하며 재분석에서도 기존 목표와 TASK를 유지한다. 상세 판단 규칙은 [AI 계획](ai-planning.md)을 따른다.

웹 등록은 기존 폴더를 카탈로그에 추가한다. 설치 후보는 알려진 작업 위치를 조회한 결과이며 전체 디스크 목록이 아니다. 요청 준비 점검은 code-agent 설치·PC 신뢰·권한 승인을 대신하지 않는다. 연결과 개발 실행은 [관리 통신 계약](code-agent-control.md)을 따른다. CLI 배정·계속 실행에는 `--control`이 필요하다.

대시보드를 종료해도 이미 접수한 별도 요청 실행기는 유지된다. 프로젝트·그룹 삭제와 업데이트 보호 조건은 [대시보드](ui.md)를 따른다. 목표 취소는 작성한 코드를 되돌리지 않으며 실행 중 시도가 있으면 먼저 종료하거나 미확인을 기록해야 한다.

검증 계약은 정확한 변경 파일·독립 검사·완료 조건·산출물을 결속한다. 후속 담당에 전달하는 계약은 소스·문서 해시·반영 커밋을 대조한다. 형식은 [검증 계약](live-verification.md), 실패 처리는 [복구](recovery.md), 인계 후 변경은 [재계획](replanning.md)을 따른다.

토큰·개인 키·호스트 오류 원문은 DB·화면·모델 입력에 넣지 않는다. 호스트 진단은 코드와 스택 첫 줄만 별도 로그에 기록한다. 외부 실행이 미확인이면 성공 처리하거나 자동 중복 접수하지 않는다.

## 남은 작업

1. 자유 목표의 AI 계획부터 검증 계약·개발·통합 완료까지 실제 모델로 연속 검증한다. 실패 수정·재계획·프로세스 중단·재부착도 포함한다.
2. 실제 Codex 개발 흐름, Claude·Codex 교차 판단의 반려·재생성 품질, 호스트 전환 인계를 검증한다.
3. 사용자 실제 PC 키와 프로젝트에서 신뢰·제어 연결을 검증하고, 실서비스 변경·운영 업데이트·다양한 업무 규모의 판단 품질을 확인한다.
4. 단계별 산출물·실행 결과·로그·생존 정보, 질문과 무관한 웹 실행 중지·취소, 계획 비교·채택, 조건별 증거와 복구 조작 화면을 제공한다.
5. 사용자 지정 프로젝트 탐색·설정 변경, 여러 그룹이나 선택 프로젝트의 요청과 프로젝트별 지시를 설계한다.
6. 원격 러너·다중 사용자·여러 PC·자동 시작, 운영 예산·인증 정책·프로젝트 지식 갱신·진단·배포 패키징을 보완한다. 공개 npm·단일 실행 파일 배포는 제공하지 않는다.
