# 분석 적용 취소와 검증 중단 복구

분석이 멈추거나 명령 반환 뒤 상태 저장이 끊긴 경우를 정리한다. 실행 중인 개발 프로세스의 강제 종료와 구분하며, 종료가 확인되지 않은 명령을 다시 실행하지 않는다.

## 읽기 전용 분석 적용 취소

```powershell
master-agent mission stop-analysis <목표ID> <분석ID> --revision <현재버전>
```

현재 계획 분석 또는 실행 전 복구 분석의 결과 적용 권한을 취소한다. 분석 ID와 목표 버전을 대조하고 판단을 기록한 뒤 상태를 `interrupted`로 남긴다. 분석 결과가 저장됐지만 계획 적용 전 중단된 경우도 처리한다. 이미 적용된 계획이나 실행을 시작한 복구는 이 명령으로 취소하지 않는다.

계획 분석을 중단하면 기존 계획의 실행 보류를 유지하고 `mission analyze`로 재분석한다. 복구 분석을 중단하면 해당 시도의 분석 예약만 해제하고 실패 상태·프로젝트 잠금을 유지한다. 새 복구는 `mission recover`로 요청한다. 일시 정지 상태라면 pause를 보존한다. 같은 분석 ID의 중복 취소는 거부한다.

이 명령은 AI 프로세스를 강제 종료하지 않는다. 읽기 전용 모델 호출은 반환 또는 기존 시간 제한까지 계속될 수 있다. 모델이 늦게 응답하더라도 이전 분석의 결과·실행 제안을 적용하지 않고 `interrupted` 기록을 보존한다. 새 분석은 별도 ID로 수행한다.

## 검증 명령 반환 기록

독립 검증 명령을 실행하기 전에 `command-run`을 저장한다. 실제 프로세스의 정상 반환을 받은 뒤 검증 전체 요약을 저장하기 전에 다음을 기록하고 봉인한다.

- 목표·시도·검증 실행 ID, 명령 ID와 계약 해시
- 정상 반환 상태, 종료 코드, stdout·stderr 해시, 시작·종료 시각

started·unknown 기록은 프로세스 종료 증거로 취급하지 않는다. 명령 반환 기록은 현재 로컬 어댑터가 관측한 정상 반환이며 전체 자손 프로세스 종료를 인증하지 않는다. 시간 초과·강제 종료·부분 실행은 이 경로로 자동 정리하지 않는다. 반영 후 검사는 별도 실행 계약이므로 여기서 복구하지 않는다.

## 검증 중단 대조

```powershell
master-agent mission unknown <목표ID> <시도ID> --revision <현재버전>
master-agent mission reconcile-verification <목표ID> <시도ID> --revision <갱신된버전> --expect-state <상태버전> --cli C:/IdeaProjects/code-agent/dist/agent/cli.js --control
```

프로세스 중단으로 verifying 상태가 남았다면 unknown으로 기록한다. 이미 unknown이면 첫 명령은 생략한다. unknown 표시는 종료 확인을 대신하지 않는다.

대조는 현재 검증 실행의 **모든 등록 명령**에 대해 계약과 일치하는 정상 반환 기록이 하나씩 있을 때만 허용한다. code-agent 작업·승인·검증 상태·세션·비활성 임대, 최초 검증 입력과 현재 파일·HEAD·선행 산출물의 일치도 확인한다. 명령 누락·중복·미반환·변조·계약 불일치·파일 변경은 보류한다.

통과하면 이전 검증을 `reconciled`로 정리하고 시도를 `awaiting-verification`으로 이동한다. 기존 결과를 성공 증거로 재사용하지 않는다. 프로젝트 잠금은 유지하고, `continue`는 막은 채 `mission verify` 또는 drive로 새 독립 검증을 수행한다. 예전 검증이 늦게 돌아와도 현재 실행 ID와 다르면 결과를 폐기한다. 새 명령을 시작할 때도 현재 시도 상태와 검증 ID를 대조한다.

## 관제와 현재 경계

`mission show`의 `analyses`·`recoveries`에서 분석 중단을, `commands`에서 명령별 반환을, `reconciliations`에서 대조 판단을 확인한다. 기록 없는 과거 버전의 실행은 소급 확인하지 않는다.

code-agent 통신 경로의 실행 중 정지·취소는 [mission stop](code-agent-control.md)으로 제공한다. 미반환 명령·중단된 반영 검사 정리와 분석 예약의 자동 만료는 지원하지 않는다. DB를 직접 수정하거나 저장된 PID로 프로세스를 종료하는 우회 절차는 제공하지 않는다. 중단·복구를 포함한 실제 모델 연속 시험은 [미검증 범위](verification.md#미검증-범위)에 남아 있다.
